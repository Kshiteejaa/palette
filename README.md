# Palette

Full-stack artist platform built with Spring Boot, React, and event-driven architecture.

## Features
- REST APIs
- Event-driven backend processing
- Artist and artwork management
- Order lifecycle handling

## Tech Stack
- Java 21
- Spring Boot
- Spring Data JPA
- H2 Database
- React (planned)

## Current Progress
- Spring Boot backend setup
- Event-driven order system
- Order APIs
